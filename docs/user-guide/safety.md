# Safety

> ⚠️ Read this **before** building, flashing or powering anything.

This device connects to **230 V AC mains**. Mains voltage can kill you and start fires. There are no "safe mistakes" here.

## Rules

1. **Never work on a powered board.** Unplug and verify with a multimeter before touching anything.
2. Use an isolated power supply and keep proper isolation barriers.
3. Enclose the device before connecting it to mains; never run it bare on a bench near people or pets.
4. Fuse the input and use wire of adequate gauge for the measured current.
5. For anything wired into a building (distribution board, DIN rail), involve a qualified electrician and follow local regulations.
6. This is a prototype/DIY device — it is **not** certified for any specific installation.
