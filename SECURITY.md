# Security

## ⚠️ Safety first

This is a **mains-voltage power meter**. The biggest "security" issue is physical safety:

- Never work on the board while it is connected to mains.
- Use proper isolation, enclosures and fusing.
- Have a qualified electrician handle anything wired into a building.
- Read [docs/user-guide/safety.md](docs/user-guide/safety.md) before touching hardware.

## Reporting a vulnerability

If you find a security issue (firmware, protocol, host app), please report it **privately** rather than opening a public issue.

**How to report:** email the maintainer martinrybka2000@gmail.com with a description and, if possible, a reproduction. Do not include live credentials or secrets.

## Scope

- Firmware (`firmware/`) and software (`software/`) vulnerabilities.
- Protocol issues (Modbus, PQDIF, network stack).
