# Contributing to OpenACME-PFM

Thanks for your interest! This project is open hardware + open software under **strong copyleft** licences — see [README.md](README.md#license).

## Before you start

- Read [docs/user-guide/safety.md](docs/user-guide/safety.md). This project works with **mains voltage**.
- Open an issue first for anything non-trivial, so we can agree on direction before you invest time.

## How to contribute

1. Fork the repository.
2. Create a branch: `git checkout -b feat/your-thing`.
3. Make your changes.
4. If you change behaviour, update the docs in `docs/`.
5. Run the relevant CI (see `.github/workflows/`).
6. Open a pull request and describe **what** and **why**.

## Conventions

- Public-facing content (docs, code comments, commit messages) is in **English**.
- Firmware: C, generated by STM32CubeMX and built with CMake.
- Hardware: KiCad 9. Keep one KiCad project per board under `hardware/`.
- Document architectural decisions as ADRs in `docs/architecture/adr/`.
