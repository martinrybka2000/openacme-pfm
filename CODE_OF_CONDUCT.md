# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

Be respectful, be kind, assume good faith. Harassment, discrimination, or unsafe behaviour is not tolerated.

## Scope

Applies to all project spaces: issues, pull requests, discussions, and any project-related communication.

## Reporting

Report violations privately to the maintainer (martinrybka2000@gmail.com). Reports are treated confidentially.
